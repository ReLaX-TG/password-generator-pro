# 🔐 Password Generator Pro

A modern, responsive, and easy-to-use password generator built with **HTML, CSS, and JavaScript**.

Create strong, random passwords in seconds with customizable security options and a clean purple-themed interface. 💜

### 🌐 Live Demo

**[Try Password Generator Pro](https://relax-tg.github.io/password-generator-pro/)**

## ✨ Features

- 🔐 **Secure password generation** using the Web Crypto API (`crypto.getRandomValues()`)
- ✏️ **Complete your password** — extend a password you enter
- 📏 **Adjustable password length** from 8 to 32 characters
- 🔠 **Customizable character options** — uppercase, lowercase, numbers, and symbols
- 🔣 **Custom symbols** — choose which special characters to include
- 📊 **Password strength indicator**
- 👁️ **Show / hide password**
- 📋 **One-click copy** with animated confirmation
- 🌍 **Multilingual interface** — English, Ukrainian, and Polish
- 📱 **Responsive design** for desktop and mobile
- 💜 **Modern glassmorphism design** with a purple gradient
- 💾 **Language preference saved** in local storage

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Web Crypto API
- GitHub Pages

No frameworks or external libraries required.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Select your preferred language.
4. Customize the password settings.
5. Click **Generate Password** and copy the result.

You can also use the live website without installing anything.

## 🔒 Security & Privacy

Password generation happens directly in your browser using the Web Crypto API.

- No account required.
- No server-side password generation.
- No passwords are intentionally sent to a server.
- No password database.

**Security tip:** Avoid using personal information in passwords, and use a trusted password manager to store them.
